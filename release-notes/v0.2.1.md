# v0.2.1

发布日期：2026-11-07

## 集群可靠性修复

- `team_create_task.priority` 明确为 `0..3`，0 最高、3 最低。
- 新增 `team_cancel_task`，可清理失效或替代任务并保留事件审计。
- ready 任务显示等待认领时长；60 秒黄色提醒，5 分钟红色异常。
- 任务卡显示活动 Lead/Worker job，区分派发、启动和实际 claim。
- 子 Agent 必须以 claim 开始，并以 submit 或 block 结束。
- Lead 必须检查 claim/submit 事件，聊天回复不能替代任务状态落板。
- 已完成 Reviewer 禁止 follow-up 复用；新材料必须创建新 thread。
- 角色模板新增跨模块字段单位、区间、枚举、更新者和真实消费者验证要求。

## 工程修复

- managed 角色、AGENTS 和项目 marker 固定写入 UTF-8/LF，修复 Windows CRLF 伪 diff。
- 团队初始化会同步新角色模板，而不是永久保留旧文件。
- 安装器同步 managed 全局角色并修复 Unicode 路径解析。
- 新增取消、认领超时和 managed 文件换行回归测试。

## 验证

- Codex Team Board：20 项测试通过。
- PRISM EMBER：34 项单元测试通过。
- `agents集群项目测试` 的 3 个残留 ready 审查任务已取消并由后续完成审查替代。
