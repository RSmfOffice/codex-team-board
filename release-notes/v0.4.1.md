# v0.4.1

发布日期：2026-11-07

## 归档语义

- 归档 `completed` 或 `failed` 集群目标时，同一目标下尚未归档的 `done` 任务会
  一起软归档。
- 恢复目标时，只恢复由该目标归档的任务。
- 用户此前单独归档的任务保留原状态，不会被目标恢复误恢复。
- 归档目标不会归档 Agent Thread，也不会调用 Codex 会话归档或删除 rollout。
- 归档任务、任务事件、worktree、分支和 merge commit 继续保留。

## Agent 访问

- `team_list_tasks(include_archived=true)` 可读取归档任务。
- 集群目标详情和 `team_cluster_status` 会返回目标关联的全部任务，包括已归档的
  `done` 任务。
- Team Board 的归档用于页面整理；它不会删除历史，也不会阻止 Agent 按 ID 读取
  相关任务和目标。

## 升级影响

- 数据库 schema 升级为 11，新增 `tasks.archived_by_goal`，用于区分目标级联归档
  与用户单独归档。
- 升级会一次性回填已有归档目标下尚未归档的 `done` 任务，并使用 metadata 标记
  保证回填只执行一次。
- 升级时自动迁移，无需手工修改数据库。

## WebUI

- 目标卡片显示“归档目标（含Done）”和“恢复目标（含Done）”。
- 归档确认框明确说明 Agent Threads 会保留并继续按复用规则工作。
